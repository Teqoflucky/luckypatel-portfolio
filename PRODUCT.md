# Product

## Platform

web

## Users

People discovering Lucky Patel through the internet: friends, peers, recruiters, collaborators, and visitors who return to find new work and experiments.

## Product Purpose

Create Lucky Patel's personal digital place as a memorable, reusable home for projects, writing, experiments, and contact.

## Positioning

A personal portfolio that feels like a living digital object rather than a resume or template. It should reward curiosity and repeated visits, with an experience that is distinctive without hiding navigation or content.

## Operating Context

The site is hosted through GitHub and Cloudflare on a custom domain, with project details added over time. The first release should remain usable and complete before real project data is available.

## Capabilities and Constraints

- Confirmed identity: Lucky Patel
- Frontend stack: React + Vite
- Public GitHub repository
- GitHub Pages or Cloudflare-compatible static deployment
- Real project names, descriptions, URLs, and assets are not yet provided
- Do not invent employment, client, achievement, testimonial, or metric claims

## Brand Commitments

- Personal, first-person, playful, and direct
- The experience should feel new and psychologically memorable, not like a generic portfolio
- The new visual identity must not inherit or reference the previous portfolio

## Evidence on Hand

- Owner name: Lucky Patel
- GitHub: https://github.com/Teqoflucky
- Existing project list and media: not yet provided

## Product Principles

- Make curiosity the primary interaction
- Preserve a clear path back to every section
- Reveal personality through behavior and composition, not clutter
- Keep the site fast, responsive, accessible, and easy to maintain
- Leave factual gaps visibly unfinished rather than fabricated

## Accessibility & Inclusion

- Keyboard navigation and visible focus states
- Reduced-motion support
- Legible text with strong contrast
- Touch-friendly controls
- No content that depends on color or motion alone
