# Lucky Patel — Pocket Observatory

## Identity

Lucky Patel's personal website is a small scientific instrument for browsing ideas, experiments, notes, and projects.

## Visual world

- Warm drafting paper ground
- Charcoal structural rules
- Cobalt for information, red for active signals, yellow for mechanical highlights
- Editorial sans for names and labels
- Georgia for a small human counterweight
- Mono type only for data, coordinates, navigation, and status

## Interface behavior

- The first viewport presents the identity and an interactive specimen finder
- The finder has three rotating observations until Lucky supplies real project objects
- Work is organized as an index, not as decorative cards
- Placeholder entries remain explicit and never invent projects
- Mobile navigation stays compact and the instrument remains usable

## Accessibility

- Semantic navigation and labeled controls
- Visible keyboard focus
- Reduced-motion support
- Text and controls remain legible without motion
